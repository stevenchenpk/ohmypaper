# ohmypaper 品牌规范

## 字标

`ohmypaper` 字标是自绘的几何单线字，没有使用任何现成字体。字标结尾的 r 同时也是一枚核验勾（Flick）：竖笔高度等于 x 高度，肩部从基线落笔处甩出一道上扬的弧，像批改时顺手一挑。

| 文件 | 用途 |
|---|---|
| `wordmark.svg` | 默认版本，浅色背景 |
| `wordmark-white.svg` | 反白版本，深色背景 |
| `wordmark-mono.svg` | 单色版本，用于单色印刷或刻章 |
| `icon.svg`、`icon-512.png` | 图标，用于头像和社交平台 |
| `../public/logo.svg`、`favicon-32.png`、`apple-touch-icon.png` | 网站图标 |

网页顶栏内联了 SVG，墨色跟随 `currentColor`，勾的颜色取 `--tick`，所以深色模式会自动适配。

## 构造网格（单位：字标坐标）

- 笔画粗细 12，圆头圆角
- 上伸线 30，x 高度 60，基线 100，下伸线 128
- 所有碗形都是半径 20 的圆，m 的拱形半径为 15

## 颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨色 | `#1A2420` | 字标正文、图标底色 |
| 勾绿 | `#2E8560` | 浅色背景上的勾 |
| 亮勾绿 | `#5FC495` | 深色背景上的勾、图标里的勾 |
| 墨绿 | `#1F4D3F` | 界面主色（按钮、链接） |
| 纸色 | `#F6F4EE` | 页面底色 |

勾只用这两种绿色。不要把它改成红色或其他状态色，否则会和核验结果的状态色混淆。

## 留白与最小尺寸

- 字标四周至少留出一个 x 高度的空白（约等于字标高度的 35%）
- 字标最小宽度：屏幕上 96 px，印刷品上 20 mm
- 图标最小尺寸为 16 px，小于 24 px 时改用 `favicon-32.png`

## 不要这样用

- 拉伸、压扁或倾斜字标
- 给字标加描边、投影或渐变
- 把勾单独拆出来使用（需要单独的符号时，请用 `icon.svg`）
- 用其他字体重新打出 "ohmypaper" 来代替字标
- 把字标放在照片或花纹上，导致对比度不足

## 中文名与标语

- 中文副标：论文提交前体检
- 英文标语：Check before you submit
- 字标旁边放中文副标时，用一条竖线分隔，副标字号约为字标高度的一半

## 字体

全部为 SIL OFL 1.1 开源字体，自托管在 `src/ui/fonts/`，不依赖 Google Fonts，国内可正常加载：

| 用途 | 字体 |
| --- | --- |
| 中文标题 | 思源宋体 Heavy（Noto Serif SC 900），只含标题用字的子集，约 7 KB |
| 英文标题、大数字 | Instrument Serif |
| 正文 | Inter + 系统中文黑体（苹方 / 微软雅黑 / 思源黑体） |
| 代码、元信息 | IBM Plex Mono |

改了 `index.html` 里的 h1、h2 文字后，要用 `scripts/subset-display-font.py` 重新生成标题字体子集，否则缺的字会退回系统宋体。
