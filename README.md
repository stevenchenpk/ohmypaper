# ohmypaper · 论文提交前体检

**查文献真伪、查格式规范、写 AI 使用声明。不替你写，帮你明明白白地过关。**

ohmypaper 是一个免费、开源的公益项目，面向中国高校写毕业论文的本科生和硕士生。打开网页就能用，不用安装软件，也不用注册；你的论文只在自己的浏览器里处理，不会上传到任何服务器。

> 当前状态：**v0.1 开发中**。参考文献核验已可用，格式体检和 AI 使用声明正在开发。

## 它能做什么

| 功能 | 状态 | 说明 |
|---|---|---|
| **参考文献核验** | ✅ 可用 | 粘贴参考文献列表，逐条到 Crossref、OpenAlex 核对，找出 AI 编造、DOI 张冠李戴、年份写错的文献 |
| **格式体检** | 🚧 M2 | 上传 docx，按本校规则和 GB/T 7714—2025 检查字体、页边距、页眉页码、参考文献格式 |
| **AI 使用声明** | 🚧 M3 | 按学校或学位学会的要求，生成 AI 使用声明 |

核验结果分四类：

- **已核实**：找到标题一致的记录。
- **信息不符**：找到了记录，但标题、年份或 DOI 对不上。
- **查无此文**：两个库都找不到，或者 DOI 根本不存在。这是虚构文献的典型特征。
- **需人工核对**：中文文献没有开放的核验接口，我们给出知网、百度学术、万方的检索链接，由你自己确认。

工具给出的是线索，不是判决。"查无此文"也可能是极新或未被收录的文献，最终判断要由你来做。

## 我们不做什么

这一条和功能同样重要：

- ❌ **不做降重、降 AI 率**，也不预测 AI 率。
- ❌ **不代写**，不生成论文正文。
- ❌ 不承诺"包过"任何检测或评审。
- ❌ 不抓取知网等需要授权的数据库。

《中华人民共和国学位法》（2025 年 1 月 1 日起施行）把论文"代写、剽窃、伪造"列为不授予或撤销学位的情形。越来越多的学校要求在论文中如实披露 AI 的使用情况。ohmypaper 帮你核实、规范和披露，而不是帮你绕过。

## 隐私

- 所有处理都在你的浏览器里完成，没有后端服务器。
- 核验时，发往 Crossref 和 OpenAlex 的只有单条参考文献的文本或 DOI，不包括论文正文。
- 不使用 Cookie，不做任何统计追踪。

## 学校规则档案

每所学校的论文要求是 `schools/` 目录下的一个 YAML 文件，内容包括格式要求、参考文献标准、AI 使用规定，每一条都标注了来源文件和核实日期。

目前收录：

| 学校 | 学位 | 届次 | 已整理 | 状态 |
|---|---|---|---|---|
| 复旦大学 | 本科 | 2026 | AI 使用规定 | 待核对 |

**欢迎补充你们学校的规则。** 不会用 Git 也没关系，看 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 本地开发

```bash
npm install
npm run dev               # 本地预览
npm test                  # 运行测试
npm run validate:schools  # 校验学校规则档案
npm run build             # 构建静态站点到 dist/
```

技术栈：TypeScript + Vite，纯静态站点，无后端。
